# Practice exercises

These exercises build on the matching course module. Finish the guided lab in each module before attempting its independent challenge.

| Exercise | Focus | Prerequisite |
| --- | --- | --- |
| [01. Your first local resources](01-what-is-terraform/README.md) | Create, update, preview, and remove files | [Module 01](../01-what-is-terraform/README.md) |
| [02. One provider, two files](02-providers/README.md) | Provider selection, lock files, and reuse | [Module 02](../02-providers/README.md) |
| [03. Tidy up one big file](03-tf-files/README.md) | File roles and safe refactoring | [Module 03](../03-tf-files/README.md) |
| [04. Lose the state, then get it back](04-state/README.md) | State commands, drift, and backups | [Module 04](../04-state/README.md) |
| [05. A configurable greeting](05-variables-outputs/README.md) | Variables, validation, and outputs | [Module 05](../05-variables-outputs/README.md) |

More exercises will be added as new modules are published.

**Safety:** Run any `terraform apply` or `terraform destroy` command yourself only after reviewing the plan. Do not commit state files, provider downloads, or secrets.
